## الطريقة الأسهل (موصى بها) — من داخل WorkBuddy

فقط اكتب لي في المحادثة:

وسأرشدك خلال العملية خطوة بخطوة. لو ما عندي صلاحية الرفع، سأجهّز لك كل شي وتسوي الخطوات بنفسك (3 دقائق).

## الطريقة اليدوية — من جهازك

### الخطوة 1: جهّز التوكن

الـ GitHub ما يقبل كلمة مرور الحساب مع git من 2021، لازم **Personal Access Token**:

1. افتح: <https://github.com/settings/tokens>
2. اضغط **Generate new token** → **Generate new token (classic)**
3. املأ:
   - **Note:** `publish whatsapp-herbs-bot`
   - **Expiration:** 90 days (أو ما تحب)
   - **Scopes:** اختر ✅ `repo`  و ✅ `workflow`
4. اضغط **Generate token** بالأخير
5. **انسخ التوكن فوراً** (يظهر مرة واحدة فقط) — يبدأ بـ `ghp_...`

### الخطوة 2: أنشئ المستودع على GitHub

1. افتح: <https://github.com/new>
2. **Repository name:** `whatsapp-herbs-bot`
3. **Description:** `🤖 وكيل ذكاء اصطناعي يرد على استفسارات عملاء متجر أعشاب وتوابل — نموذج تفاعلي`
4. اختر **Public**
5. ⚠️ **لا تختر** "Add a README file" (عندنا README جاهز)
6. اضغط **Create repository**

### الخطوة 3: ارفع الكود

افتح Terminal / Git Bash في مجلد المشروع وشغّل:

```bash
cd "C:/Users/HP-15/WorkBuddy AI/2026-09-21-02-15-20/whatsapp-herbs-bot"

git remote add origin https://github.com/moussachm/whatsapp-herbs-bot.git
git push -u origin main
```

لما يطلب منك:

- **Username:** `moussachm`
- **Password:** الصق **التوكن** (مو كلمة المرور)

أو ببساطة شغّل السكربت الجاهز:

```bash
bash publish.sh
```

### الخطوة 4: شغّل الصفحة

1. افتح: <https://github.com/moussachm/whatsapp-herbs-bot/settings/pages>
2. تحت **Build and deployment** → **Source** اختر: **GitHub Actions**
3. انتظر دقيقتين (تقدر تتابع التقدم في تبويب **Actions**)
4. الرابط النهائي:

```
https://moussachm.github.io/whatsapp-herbs-bot/
```

## ❓ مشاكل شائعة

| المشكلة                        | الحل                                                                                     |
| ------------------------------ | ---------------------------------------------------------------------------------------- |
| `Authentication failed`        | تأكد أنك تستخدم التوكن، مو كلمة المرور                                                   |
| `remote origin already exists` | `git remote set-url origin <الرابط>`                                                     |
| الصفحة تعطي 404                | تأكد أن Source = GitHub Actions وانتظر 2-3 دقائق                                         |
| Actions يفشل                   | افتح تبويب Actions واقرأ الخطأ، وغالباً الحل: Settings → Pages → Source = GitHub Actions |
