# 🤖 وكيل خدمة العملاء الذكي — للأعشاب والتوابل

نموذج تفاعلي (Live Demo) لوكيل ذكاء اصطناعي يرد على استفسارات عملاء متجر أعشاب وتوابل **تلقائياً**، بدون أي تدخل بشري.

> **🔗 العرض المباشر:** `https://moussachm.github.io/whatsapp-herbs-bot/`

---

## 💡 الفكرة

أصحاب المحلات الصغيرة يخسرون عملاء كثيرين لأنهم ما يردّون على الاستفسارات بسرعة — خصوصاً خارج أوقات العمل. هذا المشروع يبيّن كيف يمكن لوكيل ذكي أن:

- يجاوب عن **المنتجات والأسعار** فوراً
- يعطي **الفوائد وطريقة الاستخدام** لكل منتج
- يوضّح **التوصيل وطرق الدفع وأوقات العمل**
- يحوّل العميل لموظف بشري عند الحاجة

---

## ⚙️ كيف يشتغل؟

المشروع يشتغل **بالكامل في المتصفح** — بدون سيرفر، بدون API، بدون مفاتيح.

```
رسالة العميل
    ↓
[ 1 ] تطبيع النص العربي (توحيد الهمزات، إزالة الرموز والتشكيل)
    ↓
[ 2 ] البحث في قاعدة المنتجات (كلمات مفتاحية + تجريد السوابق)
    ↓
[ 3 ] مطابقة النية Intent (ترحيب، أسعار، توصيل، دفع، …)
    ↓
[ 4 ] صياغة رد طبيعي بمعلومات السعر والفوائد والمخزون
    ↓
   الرد
```

### المنطق التقني

- **تطبيع عربي:** `أ/إ/آ → ا`، `ة → ه`، `ى → ي`، إزالة التشكيل
- **تجريد السوابق:** `للنوم → نوم`، `بالأعصاب → أعصاب`
- **كلمات وقفية (Stop Words):** نتجاهل `عندكم، أبغى، هل، بكم` حتى لا تشوّش البحث
- **نظام نقاط:** التطابق الكامل للكلمة = 3 نقاط، الجزئي = نقطة واحدة
- **11 نية (Intent)** جاهزة: ترحيب، أسعار، توصيل، دفع، موقع، عروض، موظف بشري…

## 🗂️ هيكل المشروع

```
whatsapp-herbs-bot/
├── index.html          # الواجهة
├── css/
│   └── style.css       # التصميم (ألوان واتساب + هوية الأعشاب)
└── js/
    ├── products.js     # قاعدة المنتجات + محرك البحث الذكي
    ├── bot.js          # النوايا والردود (محرك الوكيل)
    └── app.js          # ربط الواجهة بالمحرك
```

### تعديل منتجاتك

كل ما تحتاجه تعديل مصفوفة `PRODUCTS` في `js/products.js`:

```js
{
  id: "herb-001",
  name: "زهرة البابونج",
  category: "أعشاب",
  price: 12,
  unit: "علبة 100 غرام",
  stock: 34,
  tags: ["بابونج", "نوم", "استرخاء", "قولون"],
  benefits: "يهدّي الأعصاب، يساعد على النوم",
  usage: "ملعقة صغيرة على كوب ماء مغلي",
}
```

## ✅ ما يجيده الوكيل

| استفسار العميل | رد الوكيل |
|---|---|
| "السلام عليكم" | ترحيب + قائمة الخدمات |
| "عندكم زعفران؟" | بطاقة المنتج كاملة (سعر، فوائد، استخدام) |
| "بكم الفلفل الأسود" | منتج الفلفل مباشرة (لا قائمة الأسعار) |
| "أبغى شي للنوم" | البابونج + فوائده |
| "قائمة الأسعار" | كل المنتجات مقسّمة حسب الفئة |
| "توصلون للبيت؟" | سياسة التوصيل |
| "أبغى أتكلم مع موظف" | رقم التواصل |

## 🔮 النسخة الإنتاجية (خارطة الطريق)

هذا النموذج يشتغل بالمتصفح لأغراض العرض. النسخة الحقيقية تربط نفس المحرك بـ:

- **WhatsApp Business Cloud API** — لاستقبال وإرسال الرسائل فعلياً
- **LLM** (GPT / Claude / DeepSeek) — لفهم السياق والأسئلة المعقّدة
- **قاعدة بيانات** — لإدارة المخزون والطلبات لحظياً
- **لوحة تحكم** — لمتابعة المحادثات والإحصائيات

الفكرة الأساسية: **نفس بنية النوايا والردود** تُستخدم كنظام احتياطي (Fallback) عندما يفشل الـ LLM أو يكون مكلفاً.
